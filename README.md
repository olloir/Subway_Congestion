# Subway_Congestion

##### 주제
- 지하철 이용객 분석
  조건: 환승역 '호선 + 역명'으로 구분

##### 분석 데이터 파일 이름
- Subway_Congestion
  https://www.data.go.kr/data/15071311/fileData.do

##### 분석 주제
###### 1. 호선별 혼잡도 분석
  세부
  - 각각 전체 시간대 평균 혼잡도 계산
  - 호선별 평균 혼잡도 순위 비교
  - 혼잡한 호선과 한산한 호선 확인
  - 평균 혼잡도 차이 분석
  시각화
  - 막대그래프: 호선별 평균 혼잡도
  - 가로 막대그래프: 혼잡도 높은 순서 정렬

###### 2. 시간대별 혼잡도 분석
  세부
  - 30분 단위 평균 혼잡도 계싼
  - 출근(07:00~09:00)·퇴근(18:00~20:00) 분석 및 비교
  - 혼잡한 시간대와 한산한 시간대 확인
  시각화
  - 선그래프: 시간대별 혼잡도 변화
  - 막대그래프: 출근 시간과 퇴근 시간 비교

###### 3. 평일 · 주말 혼잡도 비교
  세부
  - 평일과 주말 전체 평균 혼잡도 비교
  - 평일과 주말 시간대별 혼잡도 변화
  - 각각 혼잡한 시간대 확인
  - 평일 비해 주말 혼잡도가 높은 호선 파악
  시각화
  - 막대그래프: 평일·주말 평균 혼잡도
  - 선그래프: 평일·주말 시간대별 혼잡도

###### 4. 혼잡도 상위 10개 역 비교
  세부
  - 지하철역 전체 시간대 평균 계산
  - 상위 10개 역 선정
  - 평균 혼잡도 비교
  - 시간대별 혼잡도 비교
  - 가장 혼잡한 역의 최대 혼잡 시간대 확인
  시각화
  - 가로 막대그래프: 혼잡도 상위 10개 역
  - 선그래프: 상위 역들의 시간대별 혼잡도 변화
